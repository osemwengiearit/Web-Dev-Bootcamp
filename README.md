# Web Dev Bootcamp Landing Page

## 📌 Project Overview

This project is a responsive **landing page** built using **HTML and CSS**, recreated from a provided design reference image. It was developed as part of an academic frontend development assessment.

The goal of the project is to demonstrate:

- Proper use of **semantic HTML5 elements**
- Clean and structured **CSS styling**
- Ability to translate a visual design into functional web code

---

## 🛠️ Technologies Used

- **HTML5** – for semantic and accessible markup
- **CSS3** – for layout, styling, and responsiveness

---

## ✨ Features

- Semantic page structure using `header`, `nav`, `main`, `section`, `article`, `form`, and `footer`
- Hero section with call-to-action button
- Course schedule displayed using a table
- Features section with responsive card layout
- Registration form with input validation
- Clean and modern UI design
